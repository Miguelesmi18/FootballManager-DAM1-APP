# ⚽ Football Manager - DAM 1 

¡Bienvenido al proyecto **Football Manager**! Una aplicación multiplataforma diseñada para gestionar equipos, jugadores y estadísticas de liga, integrando programación en Java y una interfaz web dinámica.

## 🚀 Sobre el Proyecto
Este proyecto es una **Infoexperiencia** que permite a los usuarios gestionar su propio club de fútbol. Los datos se gestionan de forma persistente mediante archivos **JSON** y se visualizan de forma creativa tanto en la aplicación Java como en la web.

### 🛠️ Tecnologías utilizadas:
* **Java (JDK 17/21):** Lógica de negocio y gestión de POO en IntelliJ IDEA.
* **HTML5 / CSS3 (Grid & Flexbox):** Maquetación de la interfaz web.
* **JavaScript:** Carga dinámica de datos mediante `fetch` de archivos JSON.
* **Figma:** Prototipado de alta fidelidad y sistema de diseño.
* **Git/GitHub:** Control de versiones y trabajo colaborativo.

---

## 🎨 Identidad Visual
Hemos definido una paleta de colores basada en elementos reales del fútbol para mejorar la inmersión:
* **🔴 Rojo Coral (#FF5F58):** Acciones críticas y alertas.
* **🟢 Verde Campo (#BCE190):** Indicadores positivos y progreso.
* **🌑 Gris Profundo (#3D4142):** Fondo principal para reducir fatiga visual.
* **🍦 Crema Hueso (#E3DDD3):** Tipografía principal para mejor contraste.

**Tipografías:** `Montserrat` (Títulos) y `Roboto` (Datos y estadísticas).

---

## 🗺️ Mapa de Navegación (Prototipo)
El proyecto cuenta con un flujo de usuario optimizado:
1. **Landing Page:** Noticias y próximos partidos.
2. **Plantillas:** Visualización de jugadores con datos del JSON.
3. **Clasificación:** Tabla dinámica de posiciones.
4. **Formulario de Alta:** Registro de nuevos jugadores/entrenadores con validación.

## 📂 Estructura del Repositorio
* `/src`: Código fuente de Java (Clases, Modelos, Lógica).
* `/web`: Archivos de la página web (HTML, CSS, JS).
* `/data`: Archivos JSON de base de dades.
* `/assets`: Recursos multimedia (logos, fotos de jugadores, iconos).
